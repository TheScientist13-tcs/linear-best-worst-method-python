This is a Python implementation of the linear programming formulation of the Best-Worst Method by Rezaei (2016). This repository contains the following files:

    1. A worksheet demonstrating how to use the functions

    2. A Python file containing the Best-Worst Method functions

    3. A file listing the required packages

The source paper is:
Rezaei, J. (2016). Best-worst multi-criteria decision-making method: Some properties and a linear model. Omega, 64, 126-130.
